## 次の開発開始時

次の機能開発では、`AGENTS.md` の規約に従って以下を行う。

1. `main` と作業ツリーがクリーンであることを確認する。
2. `.task/000-000_...md` に最上位の作業目標を作成する。
3. `.task/000-001_...md` に最初の実装計画とチェックリストを作成する。
4. 作業ブランチを作成し、タスク文書を最初のコミットとして記録する。
5. 統合改善計画の Phase 0 から実装を始める。

`.task/` は実装の進捗を管理する場所であり、長期的な設計資料は `docs/` に置く。
