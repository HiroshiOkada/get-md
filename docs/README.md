## 検証コマンド

通常の単体・統合・E2E テストと静的検査は次のコマンドで実行する。

```sh
uv run python -m pytest
uv run ruff check .
```

外部ネットワークと実サイトへ接続できる環境では、opt-in の live E2E テストも実行する。

```sh
GET_MD_RUN_LIVE_TESTS=1 uv run pytest -m live
```

## 次の機能開発を開始するとき

次の機能開発では、`AGENTS.md` の規約に従って以下を行う。

1. 現在のブランチと作業ツリーを確認する。
2. `.task/` の既存番号に続く `NNN-000_...md` に作業目標を作成する。
3. 同じ段階の `NNN-001_...md` に実装計画とチェックリストを作成する。
4. 作業ブランチを作成し、タスク文書を最初のコミットとして記録する。
5. チェックリストの成果物と完了表記を同じコミットに記録する。

`.task/` は実装の進捗を管理する場所であり、長期的な設計資料は `docs/` に置く。
