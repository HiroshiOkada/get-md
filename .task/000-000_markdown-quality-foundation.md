# Markdown 品質改善基盤

## ゴール

`docs/plans/統合改善計画.md` の最初の実装スプリントに従い、後続の本文抽出・高速化・HTTP fast path を安全に進めるための品質基準と低リスクな Markdown 正確性改善を導入する。

## 対象範囲

- P0-1: pytest、fixture、golden test
- P0-2: benchmark と計測項目
- P1-1: URL 絶対化、非表示・明白なノイズ除去

## 完了条件

- 現行 `to_markdown()` の代表的な出力を回帰テストで確認できる。
- ネットワーク不要の HTML fixture があり、変換結果を安定して比較できる。
- `base_url` を指定した場合にリンクと画像 URL が絶対化される。
- 非表示要素と誤判定しにくい UI ノイズが Markdown から除去される。
- 変換時間、出力文字数、リンク数を同じ入力で比較できる。
- README が実装済みの新しい変換挙動を説明している。
