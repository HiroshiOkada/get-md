# Playwright 単発取得の高速化

## ゴール

Markdown の内容とスクリーンショットの品質を維持しながら、Playwright による単一ページ取得の
不要な通信と固定待機を減らし、タイムアウト時にも取得済み DOM を安全に活用できるようにする。

## 完了条件

- navigation の待機条件と本文待機を CLI から制御できる。
- 本文を壊さないリソース遮断を選択でき、スクリーンショット時は表示品質を優先する。
- navigation timeout 時の部分取得と strict mode の挙動がテストされる。
- 単発取得の起動時間と navigation 時間を分けて計測できる。
- 単体テスト、統合・E2E テスト、実サイトテスト、lint が実行される。
