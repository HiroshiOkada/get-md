# Phase 2 DOM 本文抽出基盤の実装計画

## 目的

外部の本文抽出ライブラリを導入する前に、DOM の意味要素と保守的な品質指標を使った
本文抽出を実装し、情報欠落時に文書全体へ戻る基盤を整える。

## チェックリスト

- [x] DOM 候補を本文量、段落、リンク密度、句読点、構造要素で採点する。
- [x] `full`、`dom`、`auto` の抽出モードと品質不足時の fallback を変換 API に追加する。
- [x] `--content` と `--debug-extraction` を CLI に追加し、抽出判断を表示する。
- [x] 記事、リンク中心、技術資料の fixture と単体・統合・E2E テストを追加する。
- [x] README に本文抽出の挙動とオプションを記載する。
- [x] 全テスト、統合・E2E テスト、lint、変換ベンチマークを実行する。
