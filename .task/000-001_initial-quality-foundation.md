# 初期品質基盤の実装計画

## 目的

Markdown 変換の改善を始める前に、代表 fixture と回帰テストを整備し、低リスクな URL 絶対化とノイズ除去を導入する。

## チェックリスト

- [ ] pytest を開発依存に追加し、テスト実行設定を整える。
- [ ] ネットワーク不要の HTML fixture と現行変換出力の golden test を追加する。
- [ ] `to_markdown()` に `base_url` を追加し、`href` / `src` / `srcset` を絶対化する。
- [ ] 非表示要素と明白な UI ノイズを変換前に除去する。
- [ ] 変換時間、出力文字数、リンク数を記録する小さなベンチマークを追加する。
- [ ] README に新しい変換挙動と検証コマンドを追記する。
- [ ] `python -m pytest` と `ruff check .` を実行し、結果を確認する。
