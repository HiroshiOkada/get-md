# 本文抽出と安全なフォールバック

## ゴール

`docs/plans/統合改善計画.md` の Phase 2 を進め、ページ全体から主要本文を選択しつつ、
技術資料などで重要な情報を失う場合には全体へ戻せる、説明可能な抽出基盤を提供する。

## 対象範囲

- DOM 本文候補の検出と品質スコアリング
- 抽出結果の品質判定と full fallback
- 抽出方式・候補スコア・fallback 理由のデバッグ情報
- 記事抽出ライブラリの比較評価（後続計画）

## 完了条件

- `article`、`main`、`role=main`、一般的な content class から主要本文を選べる。
- 短すぎる候補やリンク中心の候補では文書全体へ安全に戻る。
- CLI から `full`、`dom`、`auto` の抽出方法を選択できる。
- デバッグ指定時に抽出判断を stderr で確認できる。
- 単体テスト、統合テスト、E2E テスト、lint が成功する。
