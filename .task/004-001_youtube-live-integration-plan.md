## 現行実装の確認結果

2026-08-30 に Chromium とそのシステム依存を導入したうえで、次のコマンドを実行した。

```console
GET_MD_RUN_LIVE_TESTS=1 uv run pytest -m live
```

この実行環境では YouTube への navigation が `net::ERR_TUNNEL_CONNECTION_FAILED` となり、
現行実装が意味情報を返せるかは実データで確認できなかった。これは Markdown 変換処理の失敗ではなく、
ブラウザが対象サイトへ到達する前のネットワーク制約である。追加した live テストにより、接続可能な
環境では動画タイトル付きリンク、視聴回数、公開からの経過時間を一度に検証できる。
