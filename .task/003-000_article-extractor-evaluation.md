# 記事抽出ライブラリの比較評価

## ゴール

`docs/plans/統合改善計画.md` の Phase 2 に残る記事抽出ライブラリの比較を行い、
既存の DOM 抽出より情報品質を落とさずに採用できる実装を決定する。

## 対象範囲

- `trafilatura` と `readability-lxml` の同一 fixture による比較
- 本文、見出し、コード、表、画像の保持状況と処理時間の計測
- 比較結果と採否理由の文書化
- 採用した抽出方式の安全な fallback を含む変換 API・CLI への統合

## 完了条件

- 両ライブラリを再現可能な方法で比較できる。
- 記事、技術資料、表中心ページについて情報保持と処理時間を確認できる。
- 採用・不採用の理由が計測結果とともに記録される。
- 採用方式が品質基準を満たさない場合は DOM、さらに full へ fallback する。
- 単体テスト、統合テスト、E2E テスト、lint が成功する。
